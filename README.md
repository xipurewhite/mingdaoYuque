# 语雀风格明道云文档阅读器 - 使用说明

## 📖 项目概述

语雀风格明道云文档阅读器是一个基于明道云视图插件开发的文档阅读工具，提供类似语雀的优雅阅读体验。该插件支持富文本内容渲染、树状导航、文档大纲、智能搜索等功能，适用于知识库管理、文档集管理、项目管理等场景。

### 核心特性

- ✨ **语雀风格界面**：优雅的阅读体验，沉浸式文档浏览
- 🌳 **树状导航**：支持级联选择字段和关联记录字段两种导航模式
- 📑 **文档大纲**：自动解析标题结构，快速定位内容
- 🔍 **智能搜索**：全文搜索，支持路径展开和自动定位
- 📱 **响应式设计**：完美适配桌面端、平板和移动端
- 🎨 **主题切换**：支持浅色/深色主题
- 💾 **阅读进度**：自动保存和恢复阅读位置
- 🔗 **分享功能**：支持内部和外部分享链接

## ⚙️ 插件配置

### 必填配置项

在明道云插件配置界面中，需要设置以下必填项：

#### 1. 文档标题字段
- **参数名**：`title` 或 `titleFieldId`
- **类型**：字段选择器（文本字段）
- **说明**：用于显示文档标题的文本字段
- **字段类型**：文本字段（类型编号 2）

#### 2. 文档内容字段
- **参数名**：`content` 或 `contentFieldId`
- **类型**：字段选择器（富文本字段）
- **说明**：存储文档内容的富文本字段
- **字段类型**：富文本字段（类型编号 41）

### 可选配置项

#### 1. 文档分类字段（传统导航模式）
- **参数名**：`category` 或 `categoryFieldId`
- **类型**：字段选择器（级联选择字段）
- **说明**：用于构建传统树状导航的级联选择字段
- **使用场景**：适用于固定分类结构的文档管理

#### 2. 父级关联字段（关联记录导航模式）
- **参数名**：`parent_id` 或 `parentFieldId`
- **类型**：字段选择器（关联记录字段）
- **说明**：指向父文档的关联记录字段
- **字段类型**：关联记录字段（类型编号 29 或 50）
- **使用场景**：适用于动态父子关系的文档管理

#### 3. 子级关联字段（关联记录导航模式）
- **参数名**：`children` 或 `childrenFieldId`
- **类型**：字段选择器（关联记录字段）
- **说明**：包含子文档列表的关联记录字段
- **字段类型**：关联记录字段（类型编号 29 或 50）
- **使用场景**：与父级关联字段配合使用，构建完整的树状结构

#### 4. 访问模式参数
- **参数名**：`isExternal`
- **类型**：布尔值参数
- **说明**：控制内部/外部访问模式
- **取值**：
  - `true`：外部访问模式（分享链接访问）
    - 只加载URL参数中指定的单个文档
    - 隐藏左侧导航栏和搜索功能
    - 禁用新增记录功能
    - 文档选择后不可切换
  - `false` 或未设置：内部访问模式（正常使用所有功能）

#### 5. 外部分享基础URL（备选方案）
- **参数名**：`externalShareBaseUrl`
- **类型**：文本参数
- **说明**：外部分享的基础URL地址（备选方案）
- **优先级**：
  1. 优先使用 `config.worksheetInfo.publicShareUrl`
  2. 如果不存在，使用此配置项
  3. 如果两者都不存在，显示"视图未公开"
- **格式示例**：`https://470adb04ed454ac1.share.mingdao.net/public/view/6960b4a10d16bde59f87166e`

### 配置示例

```javascript
{
  // 必填配置
  "title": ["681c6663f30be243b7af083a"],           // 文档标题字段ID
  "content": ["681c6663f30be243b7af083b"],        // 文档内容字段ID
  
  // 可选配置 - 传统导航模式
  "category": ["681c6663f30be243b7af083c"],       // 级联选择字段ID（可选）
  
  // 可选配置 - 关联记录导航模式
  "parent_id": ["68a689f4b514fbf214695eed"],       // 父级关联字段ID（可选）
  "children": ["68a689f4b514fbf214695eee"],        // 子级关联字段ID（可选）
  
  // 可选配置 - 访问模式
  "isExternal": false,                             // 布尔值，是否外部访问模式
  
  // 可选配置 - 外部分享URL
  "externalShareBaseUrl": "https://xxx.share.mingdao.net/public/view/xxx"
}
```

## 📚 使用指南

### 基本操作

#### 1. 浏览文档
- 点击左侧树状导航中的文档项，右侧内容区域会显示对应的文档内容
- 支持多级文档结构，点击展开/收起按钮可展开或收起子文档

#### 2. 使用文档大纲
- 文档大纲自动解析富文本中的标题（h1-h6）
- 点击大纲项可快速跳转到对应内容位置
- 大纲会根据当前阅读位置自动高亮

#### 3. 搜索文档
- 使用顶部搜索栏输入关键词进行搜索
- 支持文档标题和内容全文搜索
- 点击搜索结果会自动展开路径并定位到目标文档

#### 4. 阅读进度
- 系统自动保存阅读位置
- 重新打开文档时会自动恢复到上次阅读位置
- 阅读进度指示器显示当前阅读进度

#### 5. 主题切换
- 点击设置按钮打开设置面板
- 选择浅色或深色主题
- 主题设置会自动保存

### 高级功能

#### 关联记录树状导航

如果配置了关联记录字段（`parent_id` 和 `children`），系统会自动使用关联记录树状导航模式：

1. **自动构建树状结构**
   - 系统根据关联记录字段自动构建父子关系
   - 支持多级嵌套结构
   - 自动检测和处理循环引用

2. **懒加载机制**
   - 大数据量时，子节点按需加载
   - 提升加载性能
   - 使用缓存减少重复请求

3. **子文档表格**
   - 在主内容区域底部显示当前文档的子文档列表
   - 支持直接点击跳转到子文档

#### 智能搜索定位

- **自动路径展开**：点击搜索结果后，系统会自动展开树状导航中的完整路径
- **滚动定位**：自动滚动到目标文档位置并高亮显示
- **子级文档支持**：支持搜索和定位到未展开的子级文档

#### 响应式布局

- **大屏幕（≥1200px）**：完整显示所有功能，包括树状导航、文档内容、文档大纲
- **中屏幕（768px-1199px）**：大纲自动收起，可通过按钮展开
- **小屏幕（<768px）**：树状导航采用悬浮覆盖模式，大纲隐藏

## 🎨 界面说明

### 布局结构

```
+------------------+----------------------------------------+  
|                  |           顶部导航栏                    |
|                  |----------------------------------------+
|   树形导航栏     |  文档大纲    |      文档内容区         |
|                  | （可折叠）   |                         |
|   (可折叠)        |-------------+                         |  
+------------------+----------------------------------------+
```

### 主要区域

1. **顶部导航栏**
   - 显示当前文档标题和状态
   - 提供编辑、分享、收藏等操作按钮
   - 显示文档统计信息（字数、阅读时间等）
   - 集成树状导航栏和大纲的显示/隐藏按钮

2. **树状导航栏**
   - 位于界面最左侧
   - 显示文档的层级结构
   - 支持展开/折叠操作
   - 当前阅读文档高亮显示

3. **文档内容区**
   - 占据界面右侧大部分空间
   - 完整渲染富文本内容
   - 支持图片查看器
   - 代码块语法高亮

4. **文档大纲**
   - 悬浮在文档内容左侧
   - 显示文档标题结构
   - 支持点击跳转
   - 当前阅读位置自动高亮

## 🐛 常见问题

### 配置问题

**Q: 插件无法正常显示文档内容？**

A: 请检查以下配置：
1. 确保已正确配置文档标题字段和文档内容字段
2. 检查字段类型是否正确（标题为文本字段，内容为富文本字段）
3. 确认工作表中有数据记录
4. 检查视图权限设置

**Q: 树状导航没有显示？**

A: 请检查：
1. 如果使用传统导航模式，确保配置了级联选择字段
2. 如果使用关联记录导航模式，确保配置了 `parent_id` 和 `children` 字段
3. 检查字段类型是否为关联记录字段（类型编号 29 或 50）
4. 确认数据中已建立关联关系

**Q: 搜索功能无法使用？**

A: 请检查：
1. 确认已正确配置文档标题和内容字段
2. 检查浏览器控制台是否有错误信息
3. 确认数据加载是否正常

### 功能问题

**Q: 文档大纲没有显示？**

A: 请检查：
1. 确认文档内容中包含标题标签（h1-h6）
2. 检查富文本内容是否正确渲染
3. 尝试刷新页面

**Q: 阅读进度没有保存？**

A: 请检查：
1. 确认浏览器允许使用 localStorage
2. 检查浏览器控制台是否有错误信息
3. 尝试清除浏览器缓存后重新测试

**Q: 分享链接无法访问？**

A: 请检查：
1. 确认视图是否已公开
2. 检查 `externalShareBaseUrl` 配置是否正确
3. 确认分享链接格式是否正确

### 性能问题

**Q: 加载速度慢？**

A: 可以尝试：
1. 减少单次加载的记录数
2. 启用懒加载机制（关联记录导航模式）
3. 检查网络连接
4. 清除浏览器缓存

**Q: 大数据量时卡顿？**

A: 建议：
1. 使用关联记录导航模式的懒加载功能
2. 分批加载数据
3. 优化数据结构，减少嵌套层级
